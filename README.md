# E-Banking System – Backend

This is the **Spring Boot** backend for the E-Banking System.  
It handles authentication, business logic, database operations, and provides a secure REST API for the frontend.

## 🚀 Features
- JWT authentication & role-based access
- Customer & account management APIs
- Transfer, credit, and debit operations
- Operation logs for auditing
- Swagger API documentation

## 🛠️ Tech Stack
- Java 17+
- Spring Boot, Spring Security
- Maven
- MySQL / MongoDB

## ▶️ Run Locally
```bash
# Install dependencies
mvn install

# Run the server
mvn spring-boot:run
