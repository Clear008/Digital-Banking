#  E-Banking System – Frontend

This is the **Angular** frontend for the E-Banking System.  
It provides a responsive user interface to interact with the backend API, including customer and account management, authentication, and dashboards.

## 🚀 Features
- JWT-based login & role-based access control
- Customer & account management (CRUD)
- Transfers, debit, and credit operations
- Dashboard with interactive charts
- Admin-only sections (logs, user management)

## 🛠️ Tech Stack
- Angular 20
- Bootstrap 5
- Chart.js (via ng2-charts)
- TypeScript

## ▶️ Run Locally
```bash
# Install dependencies
npm install

# Start development server
ng serve
